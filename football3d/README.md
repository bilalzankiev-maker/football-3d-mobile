# ⚽ Футбол 3D — мобильный матч

Полноценный играбельный 3D-футбол под Android (Chrome) и любые мобильные браузеры.
Один матч 11 на 11 против компьютера: трибуны с болельщиками, вратари, тактический ИИ,
физика мяча, табло с таймером, сенсорное управление. Полностью офлайн — Three.js лежит
локально в `lib/`.

## Как запустить на телефоне

1. Скопируйте папку `football3d` на телефон (или на любой статический хостинг).
2. Откройте файл `index.html` в Chrome (вкладка «Открыть файл»).
   Важно: держите папку целиком — рядом должны лежать `lib/`, `js/`, `style.css`.
3. Игра сама запросит горизонтальный режим и полноэкранный режим.
   Звук включится после первого касания экрана (политика браузеров).

Для десктоп-теста: `python3 -m http.server 8000` в папке, затем http://localhost:8000.

## Управление

| Действие | Сенсор | Клавиатура |
|---|---|---|
| Движение | левый виртуальный джойстик (динамический) | WASD / стрелки |
| Пас | кнопка ПАС (с направлением джойстика) | J |
| Удар | УДАР — держите для силы удара | K (удерживать) |
| Спринт | СПРИНТ — удерживать | L |
| Отбор | ОТБОР | Пробел |

Управляемый игрок выбирается автоматически (ближайший к мячу) и отмечен жёлтым кольцом.

## Матч

- 2 тайма по 45 игровых минут (4/6/10 реальных минут на матч), смена сторон в перерыве.
- Ауты, угловые и удары от ворот, свисток, голы с празднованием и рёвом трибун.
- Сложности: лёгкая / средняя / сложная.

## Структура

```
football3d/
├── index.html          разметка, меню, HUD, джойстик, кнопки
├── style.css           стили UI
├── lib/three.min.js    Three.js r152 (локально, офлайн)
└── js/
    ├── util.js         конфиг, математика
    ├── audio.js        синтезированный звук (WebAudio): толпа, удары, свисток
    ├── field.js        стадион: поле, разметка, ворота с сетками, трибуны,
    │                   ~2000 болельщиков (InstancedMesh), прожекторы, щиты
    ├── ball.js         физика мяча: гравитация, отскоки, трение, вращение, ведение
    ├── player.js       модель игрока из примитивов + процедурные анимации
    │                   (бег, удар, подкат, прыжок вратаря, праздник гола)
    ├── ai.js           тактика команд (4-4-2), прессинг, дриблинг, пасы,
    │                   удары, логика вратарей (позиционирование, сейвы, выходы)
    ├── controls.js     виртуальный джойстик + кнопки + клавиатура
    └── game.js         правила, счёт, таймер, камера, авто-смена игрока, цикл
```

## Тесты

`npm`-зависимостей нет. Headless-прогон логики (физика, ИИ, правила, полный матч
под нагрузкой) — скрипт из репозитория:

```bash
node smoketest.js   # из корня проекта; симулирует целый матч без WebGL
```
